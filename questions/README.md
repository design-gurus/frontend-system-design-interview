# Question Walkthroughs

Each page takes one common question and follows [the framework](../framework.md): the requirements to clarify, a sketch of the components and data, the decisions that matter, and what the interviewer probes. The pages stay at the level of approach and trade-offs. They are not full solutions.

| Question | Type | Main topics |
|---|---|---|
| [Design a news feed](design-a-news-feed.md) | Application | Cursor pagination, virtualization, optimistic updates |
| [Design autocomplete](design-autocomplete.md) | Component | Debouncing, stale responses, accessibility |
| [Design a chat app](design-a-chat-app.md) | Application | WebSocket, ordering, offline sends |
| [Design an image gallery](design-an-image-gallery.md) | Component | Responsive images, lazy loading, layout stability |
| [Design a collaborative editor](design-a-collaborative-editor.md) | Application | Concurrent edits, presence, offline |
| [Design a product page](design-a-product-page.md) | Application | Rendering strategy, Largest Contentful Paint, search indexing |
| [Design a video player](design-a-video-player.md) | Component | Adaptive bitrate, buffering, controls |
| [Design a real-time dashboard](design-a-real-time-dashboard.md) | Application | Update transport, render throttling, charts |

More questions without walkthroughs are in [the question bank](../cheat-sheets/question-bank.md).
